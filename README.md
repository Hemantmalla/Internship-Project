This is an internship project showcasing a full-stack restaurant web application built with Python. The project includes a Django backend with a SQLite database, static file management configured with WhiteNoise, and is prepared for production deployment using Gunicorn. The frontend is composed of HTML, CSS, and JavaScript components. The repository contains 9 commits and includes deployment configuration for Render hosting platform.

Main Function Points
Full-stack restaurant web application
Django-based backend framework
SQLite database integration
Static file collection and WhiteNoise configuration for production
Gunicorn WSGI server setup for production deployment
Render.yaml configuration for cloud deployment
Responsive design with media query updates
Technology Stack
Backend: Python, Django
Frontend: HTML, CSS (45.8%), JavaScript (37.0%)
Database: SQLite
Production Server: Gunicorn
Static File Handler: WhiteNoise
Deployment Platform: Render
Package Management: pip (requirements.txt)
